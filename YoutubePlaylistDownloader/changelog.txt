0.5:
- Version number is 0.5
- Transcode has its own simultaneous encode limit, separate from downloads
- The limit is on the transcode tab and in settings, and it changes the number of ffmpeg processes immediately
- Lowering the limit stops the extra encodes and puts those files back at the front of the queue
- A cancelled transcode can be continued
- On startup the queue and the transcode list open on the active job

0.4:
- Version number is 0.4
- Transcode list shows how long each file has been encoding
- Transcode shows elapsed time, estimated time left, estimated total time and the finish date for the whole batch

0.3:
- Version number is 0.3
- Transcode can pause a batch and asks before it overwrites a file that was already converted
- Transcode presets can be saved, updated and deleted
- An unfinished transcode batch is saved and can continue after the program closes or is stopped
- Closing while a download or a transcode is running asks whether to continue on the next launch

0.2:
- Version number is 0.2
- Transcode: choose a video codec (copy, H.264, HEVC, VP9, AV1 or audio only), a resolution, and audio codec with quality
- Transcode: MP4, MOV, M4V, 3GP, AVI, MPG, MPEG-TS and WMV for phones, tablets and TVs
- Transcode: check the files to encode, and choose a save folder. Without a folder, each file goes into a transcoding subfolder and the original stays
- Transcode list shows the current audio bitrate
- Transcode shows a progress line and a progress bar for each file
